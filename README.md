# KiCad 9.0 Cockcroft-Walton Voltage Multiplier PCB

A multi-stage voltage multiplier circuit designed in **KiCad 9.0**. This hardware uses a diode-capacitor ladder network to progressively clamp and rectify an alternating or pulsed input waveform into an elevated DC output.

## Hardware Specifications
* **EDA Tool Version:** KiCad v9.0.0+
* **Layer Count:** 2-Layer Board (Copper Pour Ground Plane)
* **Diodes:** 6x 1N4148 High-Speed Switching Diodes (SOD-123 footprint)
* **Capacitors:** 6x 10µF Multi-layer Ceramic Capacitors (1206 footprint)
* **Resistors:** 2x 1kΩ High-Power Energy Dampening Resistors (2010 footprint)
